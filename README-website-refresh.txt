# YMT Development Resources website refresh

This package contains the refreshed website files and the original site assets.

## Main navigation
- Home: `index.html`
- About Us: `aboutus_page/aboutus.html`
- Services: `service/service.html`
- Careers: `career/index.html`
- Contact: `contact.html`

## New pages
- `career/index.html` is a careers landing page linking to Part Time, Full Time and Internship.
- `contact.html` is a separate contact page with the existing address, phone, email, working hours, map and social links.

## Shared design files
- `assets/site.css`
- `assets/site.js`

The existing company logo, blue colour palette, page information, staff details, career descriptions and original images/videos are retained. Old page-specific CSS files were removed because the pages now use the shared stylesheet.

## Publishing
Upload the contents of this package to the root of the existing GitHub Pages repository, keeping the folder structure. Allow GitHub Pages to rebuild, then review the live website. Keep a copy of the current repository before replacing files so you can roll back if needed.
